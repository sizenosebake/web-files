# Pong Game 🎮

A classic Pong game built with HTML, CSS, and JavaScript.

## How to Play

### Option 1: Download and Open Locally (Recommended)
1. Download all three files (`index.html`, `style.css`, `script.js`) from the `pong-game` folder
2. Keep them in the same folder
3. Open `index.html` in your web browser

### Option 2: Raw GitHub View
1. Go to `index.html` in this repository
2. Click the **"Raw"** button
3. The game should load in your browser

### Option 3: Use Live Server (VS Code)
If you have VS Code:
1. Download the files
2. Right-click `index.html` and select "Open with Live Server"

## Game Controls

- **🖱️ Mouse**: Move left paddle up/down
- **⬆️⬇️ Arrow Keys**: Alternative control for left paddle
- **Goal**: First player to score 10 points wins!

## Features

✅ Player vs Computer AI  
✅ Smooth ball physics  
✅ Paddle collision with spin effect  
✅ Wall bounce detection  
✅ Real-time scoreboard  
✅ Responsive design  
✅ Win condition at 10 points  

## Game Objects

- **Green Paddle** (Left) - Controlled by you
- **Magenta Paddle** (Right) - Controlled by AI
- **Yellow Ball** - Bounces around the arena
- **Center Line** - Visual divider

Enjoy the game! 🎮
